Уровень 1. Проектирование
Выбран фреймворк Webpack Module Federation
Так как между Webpack Module Federation и Single SPA нет принципиальных различий, 
выберем тот, с которым лучше знакома существующая команда разработки.

В качестве host выделена главная страница приложения с компонентами:
Footer, Header, Main, ProtectedRoute.

В качестве remote - ряд микросервисов:
1) Сервис авторизации - отвечает за авторизацию и регистрацию пользователя.
В него входят компоненты: Login, Register, InfoTooltip
2) Сервис управления профилем - отвечает за аватар и описание пользователя.
В него входят компоненты: EditAvatarPopup, EditProfilePopup
3) Сервис управления картинками - отвечает за добавление и удаление картинок.
В него входят компоненты: AddPlacePopup, ImagePopup, PopupWithForm
4) Сервис управления лайками - отвечает за лайки на фото, сбор статистики и аналитики по лайкам.
В него входит компонент: Card

Уровень 2. Планирование изменений
Предполагается, что для каждого сервиса в webpack.config будут прописаны соответствующие ему компоненты как "exposes".
Для хоста же в webpack.config будут прописаны компоненты как "remotes".

В папках "blocks" каждого сервиса остались только .css файлы, необходимые для работы его компонентов.
